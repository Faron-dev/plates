# Plates

A workout tracker that installs from the browser and keeps working with no connection.

## Install

Open this site on the phone, then:

- Android (Chrome): tap **Install** on the page, or the three-dot menu, **Add to Home screen**, **Install**.
- iPhone (Safari): **Share**, then **Add to Home Screen**.

## Where the log lives

On the phone, inside the installed app. This site only serves the app's own files; nothing you log is uploaded here.
Back it up from the app: tap the status chip at the top right, then **Back up**. The same screen restores a backup on a new phone.

## What is in this folder

Plain HTML, CSS and JavaScript, plus icons and fonts. No tracking and no requests to other sites.
To host it yourself, upload every file in this folder to any static web host that serves HTTPS.

Fonts: Big Shoulders Display and Barlow, under the SIL Open Font License (see `fonts-LICENSE.txt`).
